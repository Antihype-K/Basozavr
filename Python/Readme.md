# Swarm Delivery System (RSMA + RSMA API)

Цифровой двойник системы транспортировки тяжёлых грузов группой беспилотных летательных аппаратов на гибких тросовых подвесах.

Проект сочетает физическое моделирование внешней среды (6-DOF динамика, упругие тросы, аэродинамика) в среде **RSMA** с распределенным контуром управления на **Python**, взаимодействующим через высокоскоростной протокол **RSMA API (uDTP)**.

[Подробное описание работы проекта](/Docs/Description.md)

---

## 🌟 Ключевые возможности

* **Интеграция с RSMA через RSMA API:** Передача телеметрии груза и дронов по протоколу UDP в реальном времени.
* **Многофазный автомат состояний (Flight FSM):** Управление всеми этапами миссии (плавный натяг/подъем, следование S-образной траектории с плавной ограниченной рывком скоростью, фаза удержания/стабилизации и автоматическая посадка).
* **Подавление раскачки (Anti-Sway):** Активная компенсация маятниковых колебаний груза при транспортировке.
* **Полное CSV-логирование:** Автоматическая фиксация 3D-координат всех элементов системы и сил натяжения каждого троса на каждом шаге $\Delta t$.
* **Унифицированный 4-панельный инструмент аналитики:** Визуализация 3D-траекторий, профилей высот, натяжения тросов и вида сверху в одном окне.

## 🛠 Установка и требования

Для работы скриптов управления требуется **Python 3.10+** и Git.

### 1. Клонирование репозитория вместе с подмодулями

```bash
git clone https://gitlab.grimdark.ru/development/rsma-swarm-delivery-system.git
cd RSMASwarmDelivery

```

### 2. Настройка виртуального окружения

```bash
# Для Windows (PowerShell)
python -m venv .venv
./.venv/Scripts/Activate.ps1

# Для Linux / macOS
python3 -m venv .venv
source .venv/bin/activate

```

### 3. Установка зависимостей Python

```bash
pip install -r requirements.txt

```

## 🚀 Инструкция по запуску

### 1. Запуск симуляции (Управление роем)

1. Запустите физический симулятор миссии в **RSMA** (убедитесь, что RSMA Broker активен).
2. В терминале запустите главный управляющий модуль Python:

```bash
python main.py

```

*Скрипт подключится к RSMA Broker, дождется первой телеметрии груза и выполнит полный цикл миссии (подъем, транспортировка, стабилизация, посадка). Данные о полете автоматически сохраняются в папку `logs/flight_log_YYYYMMDD_HHMMSS.csv`.*

### 2. Анализ телеметрии и построение графиков

Для визуализации результатов последнего совершенного полета запустите:

```bash
python visualize.py

```

*Скрипт автоматически найдет свежий файл лога в директории `logs/` и выведет 4-панельный дашборд с 3D-траекторией, графиками высот Z, динамикой сил натяжения тросов и планом XY.*

## 📊 Формат экспортных данных (`logs/flight_log_*.csv`)

Логгер фиксирует состояние системы на каждом шаге интегрирования ($\Delta t = 0.01\text{ с}$):

* `timestamp`: Метка времени в миллисекундах (Unix Epoch).
* `step`: Номер шага симуляции.
* `phase`: Текущая фаза автомата состояний (`LIFT`, `TRAJECTORY`, `HOVER`, `LAND`, `LAND_DRONES`, `FINISHED`).
* `payload_x`, `payload_y`, `payload_z`: Координаты центра масс груза.
* `target_cmd_x`, `target_cmd_y`, `target_cmd_z`: Целевые уставки положения груза.
* `target_drone_z`: Целевая высота полета дронов.
* `dist_to_finish`: Оставшееся дистанция до финишной точки по горизонтали.
* `avg_cable_tension`: Средняя сила натяжения по всем тросам (в Ньютонах).
* `drone_i_x`, `drone_i_y`, `drone_i_z`: Фактические 3D-координаты $i$-го дрона.
* `cable_force_i`: Сила натяжения троса $i$-го дрона (в Ньютонах).

## 📂 Структура проекта

Модульная структура проекта с разделением на управляющие алгоритмы, подмодули связи и вспомогательные утилиты:

```text
RSMASwarmDelivery/
│
├── .gitmodules                 # Конфигурация Git-подмодулей (RSMA API)
├── config.py                   # Глобальные физические константы и параметры управления
├── main.py                     # Точка входа: запуск контура управления роем
├── visualize.py                # 4-панельный аналитический дашборд телеметрии
├── requirements.txt            # Список зависимостей Python (pandas, matplotlib, numpy)
│
├── RSMA/                       # Git Submodule (RSMA API Python Client)
│   ├── Client.py               # Клиент взаимодействия с RSMA Broker
│   ├── Time.py                 # Генератор меток времени
│   └── uDTP/                   # Структуры сообщений и топиков (Pose, Float32)
│
├── control/                    # Алгоритмы группового управления
│   ├── formation.py            # Геометрия формации роя (N-угольник)
│   ├── trajectory.py           # S-образные траектории с ограничением по рывку (Jerk-Limited)
│   ├── anti_sway.py            # Контроллер активного гашения колебаний груза
│   └── flight_state_machine.py # Автомат состояний миссии (Lift -> Trajectory -> Land)
│
└── utils/                      # Вспомогательные модули
    ├── logger.py               # CSVLogger и консольный TelemetryLogger
    └── rsma_helpers.py         # Преобразователи систем координат (RSMA <-> Python)

```

### Подробное описание компонентов:

#### ⚙️ Корневые файлы

* **`config.py`**: Содержит системные параметры, шаг интегрирования $\Delta t = 0.01\text{ с}$, радиус формации, длину тросов и настройки регуляторов.
* **`main.py`**: Запускает основной цикл управления, подписывается на топики телеметрии RSMA, выполняет расчеты FSM/AntiSway и публикует целевые позиции для каждого дрона.
* **`visualize.py`**: Инструмент аналитики. Считывает последний `.csv` из директории `logs/` и строит 4 графика в одном окне: 3D-траекторию, высотный профиль $Z(t)$, силы натяжения тросов $F(t)$ и план полёта $XY$.

#### 🎮 Модуль `control/` (Алгоритмы управления)

* **`control/formation.py`**: Расчитывает координаты $N$-угольной формации роя с заданным радиусом относительно центра масс.
* **`control/trajectory.py`**: Генерирует плавную профилированную траекторию движения с ограничением по рывку ($Jerk\text{-}Limited$), исключая резкие скачки ускорения.
* **`control/anti_sway.py`**: Реализует алгоритм активного гашения маятниковой раскачки груза за счет вычисления упреждающих коррекций к позициям дронов.
* **`control/flight_state_machine.py`**: Управляет последовательной сменой фаз полёта (подъем, перемещение по траектории, стабилизация, посадка груза и посадка дронов).

#### 🛠 Модули `RSMA/` и `utils/`

* **`RSMA/`**: Внешний подмодуль для связи с RSMA. Обеспечивает сериализацию/десериализацию сообщений `Pose` и `Float32`.
* **`utils/rsma_helpers.py`**: Преобразует координаты между правой систем координат Python и левой системой координат RSMA (инверсия оси Z).
* **`utils/logger.py`**: Отвечает за запись логов полета в формате CSV и вывод форматированной консольной телеметрии в процессе полета.
